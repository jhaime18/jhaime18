# Portfolio

My personal developer portfolio showcasing my experience, projects, technical skills, and background.

## Tech Stack

* Angular
* TypeScript
* Tailwind CSS
* HTML
* JSON

## Features

* Responsive portfolio layout
* About and professional summary
* Technical skills and technology stack
* Work experience
* Academic and personal projects
* Project details and links
* Contact form
* Accessible modal interactions
* Data-driven project and experience sections using JSON
